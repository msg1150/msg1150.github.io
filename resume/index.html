  • COMBAT SYSTEM
    합류 전후의 이동 시간을 나눠 처리하고, 이동 구간 전체에서 가장 먼저 닿은 충돌을 선택합니다. 플레이어 판정은 서버에서 검사합니다.
  • BATTLE NPC NAVIGATION
    전투 NPC의 특수 이동 경로에서 일반 이동과 비용 0의 포탈 연결을 함께 비교하고, 정적 그래프와 요청별 연결 비용을 조합합니다.
  • PORTAL SYSTEM
    카메라 위치에 맞춘 출구 화면과 출구 면 클리핑을 구성합니다. 이동은 서버가 확정하며 소유 클라이언트의 예상은 통과 전후 벽 충돌 처리에만 사용합니다.
  • EDITOR VALIDATION
    검사 결과에서 수정할 오브젝트와 레벨 내 위치를 바로 확인할 수 있도록 연결했습니다.
  • DATA PIPELINE & TOOLS
    Unreal 속성 정보에서 외부 편집 화면과 검증 규칙을 구성하고, 실행 환경에 따라 적용과 저장을 구분합니다.

구현과 검증

Unreal Automation Test로 투사체 충돌·합류 지점, 1인칭 렌더링, 공간 포탈의 변환·투영·클리핑·통과 조건을 반복 검사하는 시나리오를 작성했습니다. 공개 저장소에는 테스트 실행 결과가 포함되어 있지 않습니다.

격리 복사본에서 에디터 검사·Windows 플레이·별도 프로세스 저장 복원을 구분해 검사한 기록을 PPT에 정리했습니다. 현재 자료는 작성 중이며 실행 수치는 해당 날짜의 기록입니다.

프로젝트 기반 기술 프로필 · 상세 구현과 영상은 포트폴리오 사이트에서 확인할 수 있습니다.
