## 탐색과 편집

- 메인: 이름과 직무, 대표 프로젝트, 구현 분야, 연락처.
- 프로젝트 상세: 개요·담당 범위, 핵심 사례, 추가 구현, 테스트 작성 범위, 소스 열람 안내.
- 기술 프로필: 기술과 프로젝트 경험을 간결하게 정리하고 브라우저 인쇄로 PDF 저장.
- 영상은 사용자 조작으로 재생하고 이미지는 확대해서 확인한다.
- 다른 게임은 자료가 준비된 시점에 프로젝트 배열에 추가한다. 가상 작품이나 빈 카드는 표시하지 않는다.

## 사실 확인 원칙

- 확인되지 않은 성과 수치·학력·경력·팀 인원·출시 실적은 만들지 않는다.
- 포탈 갱신 빈도와 촬영 상한은 코드 기본값이며 측정된 성능 개선 수치가 아니다.
- Automation Test는 시나리오 작성 사실만 소개한다. 공개 자료에 실행 결과가 없어 테스트 통과를 주장하지 않는다.
- 개인 구현 저장소가 전체 게임 빌드나 모든 에셋을 제공한다고 표현하지 않는다.
- 개발 시작일과 진행 상태는 PPT 기준이다. 종료 시 프로젝트 데이터를 갱신한다.
