# 수정 포트폴리오 반영 확인 기록

2026-10-21, Windows 로컬 환경. 24장으로 수정된 PPT 기준.

- 기존 18장 버전과 비교하고, 24장 전체의 출처 범위를 프로젝트 데이터에 기록했다.
- PPT의 27개 코드 URL이 생성 HTML에 빠짐없이 포함되는지 확인했다. GitHub 공개 트리에서는 사이트의 28개 코드·폴더 경로가 각 기준 커밋에 존재하는지 확인했다.
- 일반 구현은 fee0b72, AI PathLink는 별도 개인 구현 기준인 2d5b0c7로 연결했다.
- 다운로드용 PPT와 수정 원본의 SHA-256이 일치한다. 45,116,678바이트이며 버전 쿼리를 사용한다.
- 포탈 통과와 빔 보정 전후의 GIF 3개가 PPT 내부 파일과 바이트 단위로 일치한다.
- 빌드와 정적 점검 통과: HTML 4개, 내부 파일·앵커·애니메이션 리소스 125개.
- 브라우저: 데스크톱·390px 모바일에서 가로 넘침 없음. GIF 재생·정지 화면 전환과 상세 항목을 접을 때 재생 종료 확인. 콘솔 error 로그 없음.
- 개인 소개 중심의 첫 화면과 빈 증명사진 자리가 유지됨을 확인했다.
- 이미지·영상에 원본 치수를 반영해 미디어 로딩에 따른 레이아웃 변화를 줄였다.
