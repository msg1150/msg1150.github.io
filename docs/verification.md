## 상단 프로필 단일화와 기술 아이콘

- 상단 소개와 별도 프로필 칸을 하나로 통합했다. 이름·빈 사진 자리·설명·기술·연락처를 한 영역에 표시하며 다음 메인 섹션은 프로젝트다. 중복 소개 섹션과 프로필 보기 버튼을 제거했다.
- 기존 프로젝트 경험·검증 내용은 프로젝트 본문과 기술 프로필 인쇄 문서에 유지한다. 인쇄 문서는 평상시 숨기고 인쇄 때만 표시하며 기존 `/resume/`도 유지한다.
- 첨부 이미지의 주요 기술 행을 포함해 C++·Unreal Engine 5·Blueprint·NavMesh·Dijkstra·PathLink·.NET 8 WPF·Reflection·Slate에 로컬 SVG 심벌을 연결했다. 9개 모두 이름·툴팁·키보드 초점을 제공하고 모바일·인쇄에서는 이름을 표시한다.
- 주요 분야에도 게임패드·경로·도구 아이콘을 붙이고 메뉴·접기/펼치기·비교 이미지 확대의 남아 있던 문자 기호를 SVG로 교체했다.
- 메인 최상위 섹션 순서가 프로필→프로젝트→연락처이고 상단 기술 심벌이 9개임을 확인했다. HTML 중첩·내부 링크·단일 h1·기본 펼침·PPT 링크 검증을 통과했다. 브라우저 사용 제한으로 화면·실제 클릭·인쇄 대화상자는 재검증하지 못했다.

## 프로필 메인 통합과 아이콘

- 기존 프로필의 주요 기술·프로젝트 경험·검증 내용을 공통 렌더러로 메인에 통합했다. 메인 프로필은 기본 펼침이며 헤더·첫 화면·소개 링크는 `/#profile`로 이동한다. 기존 `/resume/` 주소도 같은 내용으로 유지한다.
- GitHub·메일·외부 링크·다운로드·복사·확대·닫기·인쇄·맨 위로 동작에 로컬 SVG 아이콘을 사용한다. 주요 메뉴·다운로드는 텍스트를 유지하고, GitHub 프로필·복사·인쇄·닫기·맨 위로의 아이콘 단독 제어에는 접근성 이름을 제공한다.
- 메인 프로필의 인쇄 버튼은 프로필만 출력하는 인쇄 CSS를 활성화하고 인쇄 종료 후 복구한다.
- 기본 펼침·프로필 앵커·단일 h1·PPT 내용 및 링크는 정적 점검으로 확인한다. 브라우저 사용 제한으로 실제 화면·클릭·인쇄 대화상자의 재검증은 수행하지 못했다.
