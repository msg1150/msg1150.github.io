# 수정 포트폴리오 반영 확인 기록

2026-10-22, 21장으로 재정리된 PPT 기준.

- 실제 슬라이드 배치 목록을 따라 21장 전체를 대조했다.
- 현재 PPT의 23개 코드 URL이 생성 HTML에 모두 포함된다.
- 이전 포트폴리오에서 제외된 스폰 사운드·닉네임·BGM·외형 데이터·레일건 물결 계산 설명이 공개 HTML에 남아 있지 않음을 확인했다.
- 다운로드 PPT와 새 원본의 SHA-256이 일치한다. 파일 크기는 42,704,357바이트다.
- 포탈 클리핑의 구현·검증 파일이 지정된 GitHub 기준 커밋에 존재한다.
- Node 빌드와 정적 점검 통과: HTML 4개, 내부 파일·앵커·애니메이션 리소스 121개.
- 브라우저에서 목차 순서, 클리핑 설명, 수정된 외곽선 내용과 1인칭 보정 이미지 전환을 확인했다.
- 데스크톱·390px 모바일에서 가로 넘침과 콘솔 error가 없다.
- 개인 소개와 빈 증명사진 자리가 유지됨을 확인했다.

게임 C++ 실행과 Unreal Automation Test 통과를 검증한 것은 아니다. Notion 링크는 유지하되 문서 내용은 열람 범위에 포함하지 않았다.

## 첫 페이지 전체 공개 구조 변경

- 홈에서 모든 공개 프로젝트의 핵심 구현·추가 구현·테스트와 미디어를 직접 렌더링한다.
- 프로젝트 전체와 구현·추가 구현·테스트의 details는 open 속성으로 생성하며 접힘 상태를 저장하지 않는다.
- 홈에서 개별 프로젝트 페이지로 이동하는 링크가 없고 모든 구현 사례·목차는 프로젝트별 고유 앵커로 연결된다. 기존 상세 URL은 공통 렌더러로 유지한다.
- 정적 점검에 홈 본문의 프로젝트별 전체 포함 여부, 기본 펼침, 중복 ID, 내부 앵커와 리소스 확인을 추가했다.
- 이번 변경에서는 Work 설정에서 로컬 브라우저 사용이 비활성화되어 화면·실제 클릭 동작을 브라우저로 검증하지 못했다. 이전 버전의 브라우저 점검 기록은 위 항목을 참조한다.
