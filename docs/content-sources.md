## 편집과 검증 범위

이전 PPT에서 제외된 스폰 사운드, 닉네임, AI 외형·BGM과 레일건 물결 계산은 현재 공개 페이지와 기술 프로필에서 제외했다. 기능이 없어졌다고 주장하는 것이 아니라 현재 포트폴리오에서 소개할 범위에 맞춘 것이다.

모든 게임 정지 사진은 현재 PPT의 원본과 `srcRect` 자르기를 기준으로 무손실 PNG로 다시 추출했다. FPR 비활성화는 같은 원본의 자르기 누락을 수정했고 경로 탐색은 현재 PPT의 사진으로 교체했다. 사격·데스캠 편집 MP4 대신 PPT 원본 GIF를 사용하며 포탈·빔도 현재 PPT의 원본 GIF다. 빔 GIF의 PPT 자르기는 표시 영역에 적용한다. PPT의 정지 빔 사진은 정지 화면으로, 19쪽 배치 사진은 데스캠 설명 옆에 함께 표시한다. 각 원본과 출력 해시는 `content/sources/battlearena-media.json`에 기록했다. 사진 자리는 비워 두고 생성 이미지는 사용하지 않았다.

다운로드 PPT는 원본 슬라이드·사진·링크를 유지하고 작성자·수정자·제작 도구 메타데이터를 제거한 공개 사본이다. 원본과 공개 사본의 해시·크기는 `content/sources/battlearena.json`에서 분리해 기록하고 버전 쿼리로 이전 파일 캐시와 구분한다. 현재 PPT의 20개 코드 URL과 저장소·연락처 등을 포함한 고유 링크 24개를 사이트에 유지했다. 일반 구현은 fee0b72, 전투 NPC 경로 탐색은 별도 개인 구현 기준인 2d5b0c7에 연결한다.

## 설명 도식

사용자의 스폰 후보 선택 이미지와 PPT의 3·4·6·8·14·20쪽 설명을 근거로 투사체 합류·이동 구간 충돌·포탈 경로 비용·출구 클리핑·데이터 흐름·스폰 후보 선택 도식 6개를 SVG/HTML로 작성했다. 그림은 개념 설명이며 실제 레벨 거리·측정 성능·실행 결과를 새로 주장하지 않는다. 원본 이미지·영상·GIF와 다운로드 PPT를 유지한다.

스폰 예시의 A–F는 사용 가능한 후보를 사망 위치에서 먼 순서로 정렬한 경우다. A–C 중 한 곳만 추첨하며 D–F는 제외한다. 실제 거리값이나 동일 거리 후보의 무작위 정렬은 이 고정 예시에서 재현하지 않으며, 같은 거리의 순서 결정 규칙과 `max(1, floor(N / 2))`를 별도로 명시했다.
