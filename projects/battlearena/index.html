01 / COMBAT SYSTEM

조준선과 총구 사이의 간격을 다루는 전투 시스템

해결할 문제

카메라의 조준선과 총구의 위치가 다를 때 투사체를 어떻게 이동시킬까? 큰 명중 범위가 벽 너머의 플레이어를 선택하는 일은 어떻게 막을까?

구현 방식

카메라 방향과 총구 위치로 합류 지점을 계산합니다. 한 프레임 안에서 합류 지점을 지나면 전환 전후의 시간을 나누어 이동시키고, 충돌로 정지하거나 사라진 경우 추가 이동을 중단합니다.

플레이어 명중용 Sphere와 환경 충돌용 Sphere에 서로 다른 반경을 적용합니다. 실제 이동 구간에서 충돌 시점을 비교한 뒤 Line Trace로 가려진 명중 후보를 제외합니다.

플레이어 명중은 서버 권한에서 판정하고, 확정한 결과를 이벤트로 전달합니다. AnimGraph에서는 조준에 맞춰 무기 자세를 보정합니다.

적용 결과

조준선 합류 전후의 이동 시간과 속도를 유지하고, 플레이어 명중과 환경 충돌을 구분하도록 구성했습니다.

02 / AI NAVIGATION

걷기와 특수 이동을 하나의 경로로 탐색

해결할 문제

NavMesh만으로 연결되지 않는 포탈·점프패드 구간까지 AI의 이동 경로에 포함하려면?

구현 방식

일반 이동 경로에 포탈, 점프패드, 점프, 낙하 연결을 추가합니다. 걷는 거리와 특수 이동 비용을 Dijkstra로 비교해 두 이동 방식이 포함된 경로를 선택합니다.

특수 이동 지점 사이의 거리와 연결 정보를 캐시합니다. 출발점과 도착점 후보는 추정 거리로 비교한 뒤 검증하고, 선택한 일반 이동 구간만 상세 경로를 생성합니다.

적용 결과

일반 이동과 특수 이동을 함께 고려하며, 반복 요청에서 정적 구간의 거리 쿼리를 재사용합니다.

03 / PORTAL SYSTEM

서버의 이동 처리와 로컬의 출구 화면 분리

해결할 문제

멀티플레이에서 포탈 이동을 처리하면서 각 플레이어에게 출구 쪽 시점을 보여주려면?

구현 방식

서버에서 플레이어의 위치와 방향을 변경합니다. 이동 직후에는 설정한 시간 동안 재진입을 제한합니다.

로컬 카메라를 출구 시점으로 변환하고 SceneCapture 결과를 포탈 표면에 표시합니다. 화면 점유율에 따라 렌더 타깃 해상도를 선택합니다.

코드 기본값으로 정지 상태의 갱신 빈도를 초당 5회, 프레임당 촬영 상한을 2회로 제어합니다. 이 수치는 성능 측정 결과가 아닌 설정값입니다.

적용 결과

이동 권한은 서버가 관리하고, 포탈 너머의 화면은 플레이어별 로컬 시점으로 렌더링합니다.

포탈 렌더링 코드 ↗ (새 창)
04 / DATA PIPELINE & TOOLS

Unreal 밖에서 편집하고, 검증한 데이터를 연결

해결할 문제

Unreal Editor를 열지 않고 수치를 편집하면서 데이터 타입과 저장 시점의 차이를 관리하려면?

구현 방식

Reflection으로 타입, Enum, 입력 범위를 추출합니다. .NET 8 WPF 편집기는 Manifest를 읽어 타입과 중첩 구조에 맞는 화면을 구성합니다.

JSON 저장 전 타입과 허용 범위를 검증합니다. 검증이 실패하면 오류를 표시하고 저장을 중단합니다.

Runtime에서는 메모리 값만 변경합니다. Editor에서는 값 적용과 에셋 파일 저장을 분리하고, 에셋 저장 시 연결된 JSON도 갱신합니다.

  1. Unreal Reflection
  2. Manifest
  3. WPF 편집·검증
  4. JSON
  5. Runtime / Editor
적용 결과

Unreal 속성 정보에서 외부 편집 화면과 검증 규칙을 구성하고, 실행 환경에 따라 적용과 저장을 구분합니다.

05 / EDITOR VALIDATION

배치 오류를 찾고, 수정할 오브젝트로 바로 이동

해결할 문제

플레이 전에 포탈 출구 누락이나 잘못 연결된 이동 경로를 확인하려면?

구현 방식

포탈, 점프패드, 이동 경로 연결을 모듈별로 검사합니다. 새 검사 대상을 등록해 확장할 수 있도록 구성하고 Reflection과 네이티브 연동으로 설정값을 확인합니다.

출구·목적지 누락, 잘못된 연결과 값, 경로 입구의 지면 이격을 오류로 보고합니다. Slate의 Focus 버튼을 누르면 대상 오브젝트를 선택하고 시점을 이동합니다.

적용 결과

검사 결과에서 수정할 오브젝트와 레벨 내 위치를 바로 확인할 수 있도록 연결했습니다.
