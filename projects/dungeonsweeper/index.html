층 왕복과 저장·불러오기 이후에도 같은 작업을 이어가려면?

구현 방식

탐험 시작 시 모든 층의 도면·프리팹·보상 규칙을 독립 스냅샷으로 확정합니다. 진행 중 원본 에셋을 바꿔도 현재 탐험에는 반영하지 않습니다.

층을 떠날 때 몬스터·시체·탐색 기록을 보관하고 다시 방문하면 복원합니다. 다른 층에 있는 동안에는 갱신하지 않으며 체력·가방·대시 쿨다운을 유지합니다. 층 이동 완료 후 현재 층과 방문 상태를 자동 저장합니다.

현재 작업까지 담는 독립 스냅샷

미배치 전리품이 있으면 정리 화면과 시간 정지를 복원하고, 은신 중이면 원래 숨은 좌표를 사용합니다. 반환한 스냅샷 목록을 바꿔도 실제 탐험 상태에 직접 영향을 주지 않습니다.

04 / MONSTER AI

접기펼치기
해결할 문제

목격·소음 정보를 이동과 연결하고 몸체가 벽을 통과하지 않게 하려면?

구현 방식

인식 거리와 벽 가림으로 발견 여부를 결정해 순찰·추격·공격을 전환합니다. 시야를 잃으면 마지막 목격 위치로 이동하고 해체 실패 소음의 발생 위치를 조사합니다.

발견은 빨간 느낌표, 마지막 목격 지점 추적은 노란 물음표로 표시합니다. 탐색이 끝나면 순찰 목적지를 다시 선택합니다.

EnemyAgent.cs (새 창)MonsterAwarenessIndicator.cs (새 창)

직접 이동과 격자 BFS 선택

통과 가능한 구간은 직접 이동하고 벽이 막으면 BFS 경로를 사용합니다. 선 대신 몸체 크기의 BoxCast로 검사합니다.

행동 모드·목표 셀이 바뀔 때 재탐색하며 같은 셀 안의 목표 이동은 끝점만 갱신합니다. 한 이동 호출의 지름길 검사는 최대 8개입니다. 탐색 버퍼는 메인 스레드 순차 탐색에서 재사용하며 재진입·비동기용으로 공유하지 않습니다.

몬스터·시체를 프리팹별로 대여·반환하고 해체 진행·전리품은 별도 런 데이터에 둡니다. ResetForPool로 타이머·참조·물리·시각 상태를 초기화하고 데이터 준비 후 활성화합니다.

비활성 보관 기본 한도는 프리팹별 32개·전체 128개입니다. 활성 스폰 수를 제한하는 값은 아닙니다.

감지 범위 선을 공유 UI 메시로 모으고 정점 색으로 색·투명도를 유지합니다. 표시를 끄면 메시 생성·갱신도 건너뜁니다.

현재 층만 만들고 층·장면 종료 시 소유한 메시·런타임 재질을 해제합니다. 배우 풀의 생성·파괴 비용과 표시 비용을 구분합니다.

표시 사본은 풀로 재사용하고 장면이 소유한 메시·재질·그림자는 종료 시 해제합니다.
